SELF-SERVICE SUPPORT

Knowledge Base

Quick guides for common workplace IT issues.

⌁

Wi-Fi troubleshooting

Check Wi-Fi is enabled, reconnect to the correct network, forget and re-add the network if needed, and restart the device. If the issue persists, submit a network ticket.

🔐

Password reset

Use your organisation's approved password reset process. Never share your password or verification codes with support staff.

⇄

VPN connection

Confirm your internet connection, open the approved VPN client, sign in using your organisation's instructions, and report the displayed error if connection fails.

▣

Computer running slowly

Restart the computer, close unused applications, check available storage and note any recent changes. Submit a ticket if performance remains poor.

⌘

Software installation

Request approved software through IT support. Include the application name, business purpose and device details. Do not install unapproved software.

⚠

Report a security concern

Do not click suspicious links or open unexpected attachments. Report suspicious emails, malware alerts or lost devices promptly using a high-priority ticket.
